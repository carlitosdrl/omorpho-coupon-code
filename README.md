# OMORPHO Coupon Code Landing Page

This repository contains the source code for a high-performance, single-column landing page dedicated to highlighting current promotional offers and verified discount codes for OMORPHO micro-weighted training apparel.

## Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Responsive design, custom properties)
- **GitHub Pages** (Static hosting deployment)

## Project Purpose
Developed as part of an affiliate marketing campaign to provide clean, fast-loading user interfaces for active shoppers looking for verified coupon codes (e.g., `SHOPWITHCARLOS` partner program).
